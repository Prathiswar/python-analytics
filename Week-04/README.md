# Week 04 – Python Dictionaries & Database Practice

## What I Learned

This week, I focused on Python dictionaries and learned how they can be used to organize and manage structured data.

### Concepts Practiced

- Creating and accessing dictionaries
- `.get()`
- `.keys()`
- `.values()`
- `.items()`
- Updating dictionary values
- Looping through dictionaries
- Nested dictionaries
- Storing structured records using dictionaries

## Practice Projects

I applied these concepts through small database-style projects:

- Employee Database
- Student Database
- Customer Database
- Sales Dashboard

These exercises helped me understand how dictionaries can represent structured records and how nested loops can be used to access information inside them.

## Biggest Challenge

Nested dictionaries were the most challenging concept this week.

Initially, understanding the relationship between an ID, its associated details, and the individual key-value pairs inside those details was confusing.

With repeated practice, I started visualizing the structure more clearly:

Employee/Student ID → Details → Individual Key-Value Pairs
